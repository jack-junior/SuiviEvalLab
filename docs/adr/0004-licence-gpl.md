# 0004. GPL-3.0-or-later licence

- Status: accepted
- Date: 2026-10-29

## Context
The project is open source and embeds R and R packages licensed under the GPL.

## Decision
SuiviEvalLab is released under GPL-3.0-or-later. Every dependency must have a compatible licence (MIT, BSD, Apache-2.0, LGPL, GPL).

## Consequences
Derivative works stay open. A licence check is part of the dependency review.
