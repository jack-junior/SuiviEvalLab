# Architecture decision records

One short file per significant technical decision, numbered in order. A decision is never edited after it is accepted: a later record supersedes it.

Template:

```markdown
# NNNN. Title

- Status: proposed | accepted | superseded by NNNN
- Date: YYYY-MM-DD

## Context
What problem or constraint led to the decision.

## Decision
What we chose.

## Consequences
What becomes easier, what becomes harder, what we must watch.
```
