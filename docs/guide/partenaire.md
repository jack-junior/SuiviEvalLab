# Guide du partenaire

Ce guide s'adresse au **point focal** d'une organisation partenaire, chargé d'envoyer les données de son organisation au projet. Il existe deux façons de travailler : avec l'application, ou avec le seul canevas Excel.

## Avec l'application

### Rejoindre le projet

1. Installez l'application (voir [Prise en main](manuel/accueil.md)).
2. Sur l'écran **Projets**, suivez le lien **Rejoindre un projet d'équipe**. Donnez votre nom et enregistrez votre **fichier d'identité** (`.smeid`).
3. Envoyez ce fichier à l'administrateur du projet. Il vous appellera ou vous écrira pour vérifier avec vous l'**empreinte** affichée sous votre nom : comparez les deux suites de caractères.
4. L'administrateur vous renvoie une **invitation** (`.smejoin`) et vous donne son mot de passe par un autre moyen.
5. Revenez sur **Rejoindre un projet d'équipe**, choisissez l'invitation, saisissez le mot de passe, puis choisissez où enregistrer votre copie du projet. Si le projet contient des données sensibles, donnez aussi un mot de passe pour votre copie.

Votre copie contient la conception du projet (résultats, indicateurs, calendrier, lieux, désagrégations) et les données de votre organisation seulement.

### Saisir et envoyer les données d'une période

1. Ouvrez l'écran **Réception** et choisissez la période.
2. Ouvrez l'envoi de votre organisation (ou de chacun de vos sites, selon le projet) et saisissez les valeurs, avec leurs ventilations.
3. Corrigez les alertes bloquantes ; justifiez par écrit les alertes à vérifier si la valeur est juste.
4. Joignez les pièces justificatives demandées (listes de présence, registres).
5. Cliquez sur **Soumettre**.
6. Envoyez vos changements par la façon convenue avec l'administrateur :
   - **paquet** : onglet Équipe et sécurité de la fiche du projet, « Préparer un paquet » pour l'administrateur, puis envoyez le fichier par courriel ;
   - **dossier partagé** ou **serveur** : « Synchroniser maintenant ».

Quand l'administrateur ou le validateur a traité votre envoi, son état vous revient à l'échange suivant : **validé**, ou **renvoyé** avec un commentaire. Un envoi renvoyé se corrige puis se soumet de nouveau. Un envoi validé ne peut plus être modifié de votre côté : si une correction est nécessaire, demandez-la à l'administrateur.

## Sans l'application : le canevas Excel

L'administrateur peut vous envoyer un **canevas Excel** pour une période : un classeur protégé où seules les cellules blanches se remplissent.

- Une ligne par indicateur et, s'il est ventilé, par catégorie (femmes, hommes, non précisé).
- Pour un pourcentage ou un taux, donnez le **numérateur et le dénominateur**, jamais le pourcentage lui-même.
- Pour un jalon, choisissez « Fait » ou « Non fait » dans la liste (1 et 0 sont aussi acceptés).
- Indiquez en bas la source ou le document de référence.
- **Ne déplacez, n'ajoutez ni ne supprimez de ligne** : le classeur serait refusé au retour.

Renvoyez le classeur à l'administrateur. S'il vous signale une erreur après validation, il vous demandera un nouveau classeur ; vos deux versions seront comparées avant d'appliquer la correction.

## Ce que vous voyez et ne voyez pas

Vous voyez la conception du projet et les données de votre organisation. Vous ne voyez pas les données des autres partenaires, les retours et plaintes, le budget ni les autres registres du projet. Même si vous avez accès au dossier partagé ou au serveur de l'équipe, les fichiers qui ne vous concernent pas sont chiffrés pour d'autres et ne peuvent pas être lus par votre copie.
